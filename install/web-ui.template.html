👋 欢迎使用 OMR

OMR 是桃仙智能模型路由. 4 步上手:

  1. 选择虚拟模型 (日常 / 编程 / 办公)
  2. 选择 Provider (按钮组, 多 key 一目了然)
  3. 选择路由策略 (manual / auto-balance / waterfall / priority)
  4. 开启 fallback (主 provider 挂了自动切 baozi)

fake key (***) 仅用于路由标识, 不会真调用 baozi.
